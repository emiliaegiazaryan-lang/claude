# Контент-конвейер SKEYLO

Telegram-бот, который превращает голосовые сообщения в готовый контент под три канала: Telegram, vc.ru, Threads.

Как это работает:

1. Вы шлёте боту одно или несколько голосовых подряд (или обычный текст).
2. Бот транскрибирует голосовые через OpenAI Whisper (whisper-1, язык ru).
3. Серию сообщений склеивает в один вход: либо через 20 секунд после последнего сообщения, либо сразу по кнопке "Собрать бриф". На той же клавиатуре можно выбрать, что генерировать: Telegram / vc.ru / Threads / Telegram + vc.ru / все три (по умолчанию все три).
4. Агент-парсер (claude-haiku) собирает мастер-бриф с тезисами, настроениями и пробелами.
5. Три канальных агента (claude-sonnet) параллельно пишут тексты.
6. Механическая чистка в коде, без модели: тире заменяются на дефис, восклицательные знаки и эмодзи убираются. HTML-теги Telegram не затрагиваются.
7. Агент-редактор (claude-haiku) делает лёгкую смысловую проверку и возвращает короткий вердикт: СТАТУС + ЧТО НЕ ТАК. Текст он не переписывает; при СТАТУС OK материал публикуется как есть, при НА ПРАВКУ замечания приходят отдельным сообщением.
8. Бот присылает три материала: Telegram и vc.ru - с HTML-разметкой (жирный, цитаты), у vc.ru дополнительно вынесен заголовок, Threads - цепочкой постов (первый пост, остальные ответами в тред, лимит 500 знаков на пост контролируется). Мастер-бриф - внутренний документ и в чат не отправляется; если в нём есть раздел ПРОБЕЛЫ, в конце придёт сообщение "Проверь перед публикацией" со списком. В dry-run бриф печатается целиком - для отладки.
9. Правки: ответьте (реплаем) на присланный материал текстом или голосом ("убери вторую цитату", "сделай короче и злее") - бот переделает именно этот материал с учётом правок, снова прогонит чистку и редактора и пришлёт новую версию. Переделывать можно сколько угодно раз.

Системные промпты агентов лежат в папке `prompts/` и собираются из блоков: базовые правила агентов - из `skeylo-agenty-kontent-konveyer.md`, стилевая карта и эталоны - из `skeylo-stilevaya-karta.md`. Стилевые блоки подставляются перед форматными правилами: Telegram получает карту и три эталона, vc.ru - карту, формат и два эталона, Threads - карту. Правка промпта не требует правки кода - отредактируйте нужный файл в `prompts/` и перезапустите бота.

Экономия на токенах: статичные системные промпты (карта, эталоны, формат-правила) помечены cache_control, поэтому повторные прогоны считаются по кэш-цене (~10% за закэшированную часть). Меняющийся мастер-бриф в кэш не попадает.

## Структура проекта

```
app/
  bot.py            # Telegram-бот (aiogram 3): приём серии, дебаунс, кнопка, ответы
  pipeline.py       # оркестрация: вход -> бриф -> 3 текста -> чистка -> редактор
  agents.py         # вызовы Claude API (парсер, 3 канала, редактор) с кэшированием
  cleanup.py        # механическая чистка: тире, восклицания, эмодзи
  transcription.py  # Whisper API
  dryrun.py         # тестовый прогон без Telegram
  config.py         # настройки из .env
  prompts.py        # сборка системных промптов из блоков prompts/
prompts/            # системные промпты шести агентов
.env.example        # шаблон переменных окружения
```

## Что понадобится

- Python 3.11 или новее.
- Токен Telegram-бота.
- Ключ Anthropic (Claude API).
- Ключ OpenAI (Whisper API).

Важно: Anthropic API недоступен с российских IP. Локально запускайте через VPN, а для постоянной работы разместите бота на зарубежном хостинге (инструкция для Railway ниже).

### Как создать бота у BotFather

1. Откройте в Telegram диалог с @BotFather.
2. Команда `/newbot`, затем задайте имя и username бота (username должен кончаться на `bot`).
3. BotFather пришлёт токен вида `123456789:AA...` - это `TELEGRAM_BOT_TOKEN`.
4. По желанию: `/setuserpic` для аватарки, `/setdescription` для описания.

### Где взять ключи

- Anthropic: https://platform.claude.com -> API Keys -> Create Key. Это `ANTHROPIC_API_KEY`.
- OpenAI: https://platform.openai.com/api-keys -> Create new secret key. Это `OPENAI_API_KEY`. На балансе должно быть хотя бы несколько долларов - Whisper стоит 0.006$ за минуту аудио.

## Как заполнить .env

```bash
cp .env.example .env
```

Откройте `.env` и впишите три обязательные переменные:

```
TELEGRAM_BOT_TOKEN=токен от BotFather
ANTHROPIC_API_KEY=ключ Anthropic
OPENAI_API_KEY=ключ OpenAI
```

Остальные переменные необязательны. Полезная: `TELEGRAM_ALLOWED_USER_IDS` - ваш Telegram id (узнать можно у бота @userinfobot), чтобы посторонние не тратили ваши ключи.

Никогда не коммитьте `.env` - он уже в `.gitignore`.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m app.bot
```

Бот работает через long polling - никакой публичный адрес не нужен. Напишите боту `/start` и пришлите голосовое.

## Тестовый режим (dry-run)

Прогоняет текст через весь пайплайн без Telegram и печатает результат в консоль. Нужен только `ANTHROPIC_API_KEY`. Удобно для обкатки промптов:

```bash
python -m app.dryrun "Селлер на WB получил штраф за подмену товара, что делать и как оспорить"
```

## Деплой на Railway

Railway - зарубежный хостинг, деплой из GitHub, около 5$ в месяц.

1. Запушьте репозиторий на GitHub (без `.env`).
2. Зарегистрируйтесь на https://railway.app (можно через GitHub).
3. New Project -> Deploy from GitHub repo -> выберите этот репозиторий.
4. Railway определит Python-проект по `requirements.txt`. Задайте команду запуска: Settings -> Deploy -> Custom Start Command:
   ```
   python -m app.bot
   ```
5. Вкладка Variables -> добавьте `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` (и при желании `TELEGRAM_ALLOWED_USER_IDS`).
6. Deploy. В логах должно появиться "Бот запущен, жду сообщения".

Обновление: любой push в ветку по умолчанию автоматически передеплоит бота.

## Настройка агентов

- Модели: канальные агенты - `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-4-6`), парсер и редактор - `ANTHROPIC_FAST_MODEL` (по умолчанию `claude-haiku-4-5`).
- Температуры: парсер и редактор 0.2, канальные агенты 0.6 - меняются через `.env`.
- Тексты промптов: файлы в `prompts/` (`parser.md`, `telegram.md`, `vcru.md`, `threads.md`, `editor.md` плюс стилевые блоки `style_card.md`, `etalons_telegram.md`, `format_vcru.md`, `etalons_vcru.md`, `vcru_html.md`).

## Обработка ошибок

- Все вызовы Claude и Whisper ретраятся до 3 раз с экспоненциальным бэкоффом (таймауты, rate limit, 5xx).
- Если какое-то голосовое не распозналось, бот сообщит его номер и продолжит с остальными.
- Ключи в логи не пишутся.
